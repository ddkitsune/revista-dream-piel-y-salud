# Revista Dream Piel y Salud - Plataforma Web Editorial & Comunitaria

Plataforma digital interactiva y directorio médico para la **Revista Dream Piel y Salud**.

## Vistas Incluidas (21 Vistas Clave)
- **Revista Principal**: `index.html` (Hero híbrido con podcasts oficiales y artículos destacados)
- **Directorio Médico**: `especialistas.html` y `perfil-especialista.html`
- **Red Social Dream**: `social.html`, `post-detalle.html`
- **Contenido Editorial**: `articulos.html`, `articulo-detalle.html`, `caso-clinico.html`, `kiosco-revista.html`
- **Podcasts Hub**: `podcasts-hub.html`
- **E-Commerce & Consultas**: `marketplace.html`, `producto-detalle.html`, `carrito.html`, `checkout.html`, `confirmacion-pedido.html`
- **Portal Médico & Telemedicina**: `login.html`, `dashboard-doctor.html`, `expediente-paciente.html`, `chat-medico.html`, `videoconsulta-sala.html`, `registro-doctores.html`, `suscripcion.html`

## Stack Tecnológico
- HTML5 semántico
- Tailwind CSS (via CDN) con paleta personalizada Terracota / Warm Editorial / Blue Eclipse
- Vanilla JavaScript (`app.js`) para estado local, sliders, audio player y carrito
- Google Fonts (`Bodoni Moda`, `Plus Jakarta Sans`, `Lora`)
